## 给接手人的三句话

1. **先读 `03-踩坑清单.md`**——本项目的坑绝大多数不是"没思路"，而是环境细节（adb 掉线、mksh heredoc、SELinux 剥 setuid、bounding set 限制、重复绑定 panic）。
2. **真 root 操作不要用 `su`**——su 只拿到 0xc0 caps，写 shell 目录会莫名失败；用 `roothelper + root_cmd.sh` 机制（kernel 上下文，全 caps），见 `docs/01-原理详解.md` §6。
3. **动手改 /system 前确认 `images/system_backup.img` 完整**（应为 1073741824 字节），它是恢复 /system 的唯一途径——本设备没有对应的 OTA 包可刷。
