## 1. 通用操作方法

```bash
# 列出全部包
$A shell "pm list packages -s"
# 禁用（可逆，推荐）
$A shell "pm disable-user --user 0 <package.name>"
# 彻底删除（不可逆，需 /system rw）
$A shell "su -c 'mount -o remount,rw /system && rm -rf /vendor/app/<Dir>'"
# 开机自启（receiver）也可以只斩组件，粒度更细：
$A shell "su -c 'pm disable <pkg>/<component>'"
# 查看哪些包在耗资源/开机自启
$A shell "su -c 'dumpsys package <pkg> | grep -E \"receiver|service\"'"
```

写 /system 前走 roothelper/root_cmd.sh 通道（`mount -o remount,rw /system`），因为 su 的 caps 不够——见坑 #C2。

注意：本机大量小米预装包的实际 APK 在 **/data/app**（商店升级后的新版本），这些用 `pm disable-user` 即可，不需要动 /system；位于 /system/vendor/app 的才是原装顽固件。

### 2.5 其他开机噪音（非 APK，可顺带处理）
- 开机广告视频缓存：/data/local/adlog、/data/local/tmp 下的广告缓存目录（观察后删）
- `dumpsys package` 里 enabled=false 的历史遗留即可无视

## 3. 精简后验收

1. 重启电视，确认桌面/直播/设置/投屏正常；
2. `pm list packages -d` 查看禁用清单；
3. 观察 10 分钟开机后 `top`，确认无广告/上报进程复活（`pm disable` 的包不会被拉起；rm 的包若被 init 服务引用会无限重启报错，此时改回 disable 方式）；
4. 内存与开机速度对比记录（可选）。
