## 3. 逆向与分析脚本（根目录）

| 脚本 | 用途 |
|---|---|
| `ko_probe.py` | 列 `mali.ko` 符号/尺寸/调试信息（确认 `mali_mem_validation_check` 只有 28B） |
| `ko_disasm.py` | 反汇编 `mali.ko` 指定函数（capstone） |
| `ko_relocs.py` | 结合 `.rela.text` 解析 `bl` 的真实目标（`r_offset` 相对 `.text`） |
| `so_syms.py` | 列 `libGLES_mali.so` 的函数符号（按地址区间过滤） |
| `scan_imm.py` | 扫 libMali 里的 `movw/movt` 立即数构造点，定位命令流构建器 |
| `find_ldr.py` | 扫 ARM/thumb 的 `ldr [pc,#imm]` 字面量引用 |
| `disas_region.py` | 按地址区间反汇编（ARM/thumb 切换过几次，以实际为准） |
| `disas_fill.py` | **本次新增**：反汇编 `libGLES_mali.so` 0x8b240 起区域（用于核对 fill 构建器） |
| `scan_shaders.py` | **本次新增**：在 libMali 里找嵌入式 shader 字面量（结果：无现成 blob，见 [02 §E](02-技术事实.md)） |
| `apk_strings.py` / `dex_dump.py` | APK/dex 字符串与类字节码 dump（androguard） |
| `scan_bin.py` ~ `scan_bin7.py` | eMMC dump 分析流水：扫 `ANDROID!`、找内核版本串、找固件版本号、找 1275 痕迹 |
| `extract_boot.py` | 解析 Android bootimg 头并切出 kernel（`kernel_addr=0x1080000`） |
| `decomp_kernel.py` | gunzip 内核 + 打印版本串 |

> 环境提示：这些脚本用的是**系统 Python**（`C:\Users\22856\AppData\Local\Programs\Python\Python313\python.exe`，已装 `pyelftools`/`capstone`/`androguard`），**不是** DSH 自带 python（那个没有 elftools）。
